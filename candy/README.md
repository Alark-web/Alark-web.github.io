# Мир биотехнологий — сайт продукта

Одностраничный сайт образовательного набора с настоящими культурами микроорганизмов.
Без сборки и зависимостей: чистые HTML, CSS и JavaScript. Открывается двойным кликом
по `index.html`, разворачивается на любой хостинг простым копированием папки.

---

    metodichka.pdf         три сценария занятий - производственный файл, с сайта не скачивается
                          (на сайте только тизер guide-preview.jpg)
    kartochki-a5.pdf       шесть карточек А5, предоставлены заказчиком - тоже не скачивается

  og-cover.html         исходник обложки для соцсетей
  oferta.html            исходник assets/docs/oferta.pdf
  metodichka.html         исходник assets/docs/metodichka.pdf

Исходники фото (полная коробка с трёх ракурсов, сетка из шести чашек, PDF карточек) заказчик
кладёт в `pictures and cards/` вне сайта; оттуда их вырезают/перегоняют в `assets/img/` и
`assets/docs/`. Соответствие «фото чашки → культура» см. в разделе ниже «Что заменить перед
запуском» - определяется по описанию цвета колоний в карточках, самого фото стенда с 2026-08-31
в проекте больше нет (заменено на студийные снимки).

PDF-документы в `assets/docs/` собираются печатью HTML-исходников из `tools/` через headless Chrome:

```bash
chrome --headless=new --no-pdf-header-footer --virtual-time-budget=8000 \
  --print-to-pdf=assets/docs/oferta.pdf tools/oferta.html
```

(так же для `metodichka.html`; `--virtual-time-budget` нужен, чтобы шрифты Google Fonts и
изображения успели подгрузиться до печати). `kartochki-a5.pdf` - не сгенерированный файл, а
копия `pictures and cards/Карточки_микроорганизмы_A5 (1).pdf` от заказчика; при замене карточек
просто кладите новый PDF поверх `assets/docs/kartochki-a5.pdf` и перерендерите
`assets/img/card-preview.jpg` (см. ниже).

`card-preview.jpg` собирается рендером страницы PDF через PyMuPDF:

```bash
python -c "
import pymupdf
doc = pymupdf.open('assets/docs/kartochki-a5.pdf')
pix = doc[3].get_pixmap(matrix=pymupdf.Matrix(3, 3))  # страница 4 = Rhodococcus
pix.save('scratch.png')
"
```

(масштабировать `scratch.png` вдвое и сохранить как `assets/img/card-preview.jpg`).

## Что умеет сайт

**Интерфейс**
- Светлая и тёмная темы: переключатель в шапке, выбор запоминается, по умолчанию — как в системе.
- Липкая шапка с индикатором прочитанного, подсветкой активного раздела и мобильным меню.
- Появление блоков при прокрутке, счётчики, параллакс в первом экране, бегущая строка.
- Кнопка «наверх», всплывающие уведомления, плавная прокрутка по якорям.

**Продуктовые блоки**
- Интерактивная комплектация: наведение на пункт списка подсвечивает соответствующий элемент набора.
- Каталог культур с фильтром по группам (дрожжи, бактерии, микроводоросли, микрогрибы).
- Карточка культуры в модальном окне: только фото — переключатель «чашка Петри ↔ под микроскопом»,
  увеличение по клику, листание стрелками, Esc — закрыть. Текстовых описаний намеренно нет.
- Технология производства: шаги синхронизированы с визуалом при прокрутке.
- Блок «Почему «Мир биотехнологий»?» — пять карточек с ключевыми преимуществами.
- Слайдер отзывов с автопрокруткой, свайпом и точками.
- Конфигуратор набора: комплектация, дополнения, количество, автоматические скидки за объём,
  живой пересчёт итога и подсказка про доставку.
- Форма заявки с валидацией, переключателем «частное лицо / организация» и экраном успеха.
- FAQ с поиском по вопросам и аккордеоном.

**Техника**
- Мета-теги Open Graph и Twitter, canonical, JSON-LD (Organization, Product, FAQPage).
- Доступность: пропуск к содержанию, фокусные состояния, aria-атрибуты, поддержка клавиатуры,
  уважение `prefers-reduced-motion`, стили для печати.
- Изображения — настоящие фотографии (JPEG), сжаты и обрезаны под вывод; страница весит несколько мегабайт.

## Как запустить

Достаточно открыть `index.html` в браузере.

Для проверки «как на сервере» удобнее поднять локальный сервер:

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Как менять контент

| Что | Где |
|---|---|
| Тексты секций, заголовки, FAQ | `index.html` |
| Названия и группы культур | массив `CULTURES` в начале `assets/js/app.js` |
| Цены, состав комплектаций, скидки за объём | объекты `EDITIONS` и `TIERS` в `assets/js/app.js` (и цены в разметке блока `#pricing`) |
| Цвета, отступы, скругления, тени | блок токенов `:root` в начале `assets/css/styles.css` |

### Перерисовать изображения культур

```bash
python tools/gen_cultures.py
```

Скрипт детерминирован: одинаковый `seed` даёт одинаковую картинку. В файле `tools/gen_cultures.py`
у каждой культуры настраиваются цвет среды, цвет колоний, тип роста (`punctate`, `mucoid`, `lawn`,
`diffuse`, `mycelium`), число и размер колоний.

### Перерисовать обложку для соцсетей

```bash
chrome --headless=new --screenshot=assets/img/og-cover.png --window-size=1200,630 tools/og-cover.html
```

### Подключить отправку заявок

В `assets/js/app.js` найдите обработчик `form.addEventListener("submit", ...)` в модуле `leadForm`.
Данные уже собраны в объект `data` — остаётся отправить их:

```js
await fetch("https://formspree.io/f/ВАШ_ID", {   // или свой бэкенд, или Яндекс.Формы
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(data)
});
```

Чекбокс согласия на обработку персональных данных уже ссылается на `privacy.html` — при смене
домена или реквизитов организации обновите текст в этом файле.

## Публикация

Любой статический хостинг: Timeweb, Beget, Reg.ru, GitHub Pages, Netlify, Vercel, Object Storage.
Загрузите содержимое папки (кроме `legacy/` и `tools/` — они нужны только для разработки) в корень сайта.

Рекомендации после выкладки:
- включить HTTPS и сжатие (gzip/brotli) — SVG и CSS сжимаются в 4–6 раз;
- настроить кэширование `assets/` на длительный срок;
- подключить аналитику (Яндекс.Метрика) и цель на отправку формы.
